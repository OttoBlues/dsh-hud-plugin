# HUD V0.5.16 Desktop 进程识别修复候选

在 DSH 0.2.2-rc.1 Desktop 实机中，V0.5.14 的独立 HUD 报告无法找到 Host PID 所属的主窗口。可见 DSH 窗口实际由 Electron Shell 持有，Host 是 Shell 启动的独立子进程；把 Host PID 当作 Shell PID 会使启动直接失败。

本版先尝试明确提供的 Shell PID；如果它与 Host PID 相同但未找到窗口，则仅在实际父子关系、两个进程的 DSH 可执行文件路径和创建时间均通过核验后查找父进程中的唯一主窗口。启动及异常退出后的恢复使用同一规则；无法唯一识别时停止，不隐藏或恢复其他程序窗口。脚本仍限制匹配 Chromium 主窗口类和最小尺寸。

验证分层：自动化检查覆盖父进程误匹配、异常恢复参数及脚本编码；使用当前真实 Desktop 进程进行的只读定位与错误父 PID 拒绝属于进程识别验证，不代替安装候选包后在 Desktop 中操作「打开独立 HUD」「返回 DSH」和异常恢复。当前候选未发布至公开 Unstable 或正式 Release，保留 V0.5.14 本机包供回退。
