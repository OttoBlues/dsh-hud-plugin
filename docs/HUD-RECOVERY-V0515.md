# HUD V0.5.15 更新恢复修复候选

本轮修复 V0.5.14 审计发现的策略写入无限等待、自动更新明确失败后无法恢复及旧版 CI 发布任务误提交不存在目录。此版本是源码和本机验证候选，不代表已经发布到 Unstable 或通过 DSH Desktop 验收。

## 行为

- 策略写入等待 12 秒；超时显示结果未确认并恢复控件显示。DSH 的 ConfigForm 为每个表单串行排队，且不提供取消接口，因此原请求未结束时不追加重复写入；请求最终结束后允许重试。无法确认的结果不被描述为“原设置未更改”。
- 后台自动安装的账本保留唯一尝试、状态和失败重试时间。Plugin Manager 明确返回失败时，间隔至少五分钟重试，最多总共三次；显式取消、仍在执行、异常断连和未知结果均不自动重放。重启后保留可确认的失败状态；旧账本的未知状态保守视作未确认。
- 自动安装 90 秒未返回时提示结果未确认，并保持同一 Host 的安装锁直到实际请求结束，避免重复发起；客户端应以 DSH 插件清单和 Host 状态核对最终结果。
- V0.5.10、V0.5.12 历史 CI 归档任务只在源码版本与任务目标匹配时执行提交步骤，不会因旧目录不存在导致后续版本 CI 失败。

## 验收与回退

需核对策略正常保存、拒绝、超时及迟到响应；明确失败后的退避、最多重试次数、重启恢复；取消和未知状态不重复提交；CI 两种旧发布任务在版本不匹配时不执行 Git 提交。Windows DSH 仍需验证 Host 状态、独立窗口进入和返回、同进程连续升级、重启和失败恢复。自动化测试不能替代这些真实运行验收。

当前公开 Unstable 仍是 V0.5.10，Released 为空。本机应保留已安装的 V0.5.14 候选包和配置备份作为回退材料；任何版本切换、重启或重新安装都应避免影响正在运行的用户任务。
