# HUD V0.5.1 · VECTOR / ENHANCED HUD 视觉候选

> 设计提案，尚未经用户定稿。目标是在 DSH 内构建增强科幻线条式 HUD，代替传统厚重的深色圆角 Dashboard。

## 视觉规则

| 元素 | 候选规则 |
| --- | --- |
| 底色 | 深海军蓝 `#030c15` 为底，低对比度 38px 细网格 + 径向渐变 |
| 主强调色 | 青色 `#77f5f0`，用于有效动作、角标、实时读数 |
| 辅助色 | 电蓝 `#7dbfe4`，用于导航引导与状态刻度 |
| 警示色 | 沙金 `#f1d59b`，只用于部分检查失败、警告信息 |
| 面板骨架 | 13px 切角多边形 + 约 1px 的半透明矢量轮廓线；不采用大面积实色圆角卡片 |
| 角部标识 | SVG 短线、断开的导轨、标签编号，纯装饰不拦截鼠标操作 |
| 视觉层级 | HUD 标识、系统线、态势标题、读数模块、会话面板、信息页脚 |
| 可读性 | 主文字高对比度，低对比网格不能压住内容；动效可选而非强制 |
| 数据真实性 | 会话计数与运行中数量来自 DSH hooks；装饰性刻度不冒充监控数据 |

## 工作界面

- 保留 V0.5.0 原来的总览、会话、组件中心与「返回 DSH」入口，改用窄边框、切角、局部发光、准星式线条。
- 标题下用矢量线条分隔各模块，读数区域用细线标签与大数字代替普通统计卡片。
- 窄窗口必须能滚动且不能失去退出 HUD 的按钮。HUD 不强制抢占系统通知与审批。
- 原生 DSH 页面上的 HUD 小按钮也改用同类矢量切角视觉。

## 组件中心 / 手动检查更新

- 组件列表与更新设置使用相同的线框容器与色彩规范。
- 顶部「检查更新」按钮只触发 Host 使用允许的公开 GitHub 更新源重新获取组件索引和正式/试验通道清单；**不会安装组件**。
- UI 反馈：待检查、扫描中、已完成、部分通道失败、整个更新源失败，展示检查时刻与主源/迁移源。
- 发现组件发布通道不可用时，不将其当成有效「已是最新」，提供错误文本以便诊断。
- 继续保留自动更新的三个授权门槛和包体 SHA-256 校验，不添加任何本地 Runner 依赖。

## U051 用户人工验收

| 检查 | 通过条件 |
| --- | --- |
| V051-1 | HUD 主界面体现线框、切角、扫描线与科幻驾驶舱，而非普通圆角卡片 |
| V051-2 | 组件中心与 HUD 主界面使用同套视觉；文字清晰、按钮可点击 |
| V051-3 | 点击「检查更新」后能刷新最新试验版，不需要重启 DSH |
| V051-4 | 检查中、检查完成、失败时有不同状态提示及具体错误 |
| V051-5 | 点击检查不触发安装；更新包仍需「更新 → 确认」 |
| V051-6 | HUD / DSH 切换、窗口缩放、原会话与审批行为没有回归 |

**定稿门槛：** 用户使用真实 DSH 截图和交互反馈确认线条语言、信息密度、配色强弱后再把视觉规范设为最终版。暂不进入 Released。
