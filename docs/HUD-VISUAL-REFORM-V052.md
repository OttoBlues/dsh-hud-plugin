# HUD V0.5.2 视觉修正任务书｜驾驶舱面板与 DSH 主题边界

> 状态：候选设计修正版，待用户在 Windows DSH 实机视觉验收。不将任何视觉规则自动认定为最终定稿。

## 设计分区原则

### HUD 主工作台｜沉浸式驾驶舱

- HUD 是覆盖 DSH AppFrame 的第二套工作模式，视觉基座保持深色，原生 DSH Session、审批和任务执行逻辑不被替换。
- 背景属于**舱体**：低亮深蓝黑色 `#07131f`，降低网格和径向亮斑的存在感。背景不承载最强对比，取消密集 38px 可见网格。
- 内容模块属于**嵌入式仪表面板**：外层深蓝钢壳、中间极细轮廓、内侧暗色信息腔、顶部柔和机械高光，底部有收敛阴影，不再像一片薄的透明网页卡片。
- 青色 `#6ed7dc` 用于数值和选中状态，次要信息偏蓝灰 `#9eb5c1`，警示保留少量暖金；文字清晰优先于发光效果。
- HUD/DSH 主界面仍有总览、会话、组件中心和返回 DSH 入口；默认使用原 DSH，进入 HUD 必须主动操作。

### DSH 组件中心｜原生管理页面

- 组件中心不再继承 HUD 主工作台的背景、网格、切角边框、暗蓝色文字与雷达装饰。
- 背景透明、文字继承 DSH 主题；卡片使用 DSH 常规圆角、轻边框、表单开关；兼容浅色和深色 DSH 主题。
- HUD 品牌点缀仅用于细小青色状态标识、标题旁的功能识别色或主操作按钮的轻微强调，不改变整页底色。
- 「检查更新」保留于仓库连接状态区，采用 DSH 常规按钮风格；成功、检查中、部分失败、失败、上次检查时间与源信息清晰可见。

## 线条系统与几何修正

1. **去除变形根因**：V0.5.1 角线 SVG 使用 `viewBox="0 0 100 100"` 并强行 `preserveAspectRatio="none"` 拉伸到不同比例的面板；这会把原本固定斜率变成随宽高变化的大斜线。V0.5.2 停止将这种拉伸 SVG 用作面板轮廓。
2. **固定像素几何**：面板切角固定 `12px`；内层嵌板保持与外层一致的切角比例，全部通过 CSS 像素尺寸计算，不基于容器百分比绘制斜边。
3. **做减法**：每个面板只允许一层固定 2px 金属外框 + 一层暗色信息腔 + 少量顶部 1px 高光；少量顶部状态条可选。删除跨面板散落的短线和漂浮角线。
4. **准星移除/降级**：当前大号准星不显示真实状态，先从主状态面板移除。需要雷达或瞄准相关功能时，必须与真实数据绑定，不使用假数据显示。
5. **版式安全**：窄窗口下数据区自然换行，所有内容可滚动；不会出现拉伸后的边线穿过文字；`返回 DSH` 必须保持可见且可点击。

## 配色协调

| 层级 | HUD 工作台 | DSH 组件中心 |
| --- | --- | --- |
| 页面背景 | 深蓝黑低对比舱体 | 完全交给 DSH AppFrame 主题 |
| 面板 | 不透明度高、双层深色实体驾驶舱 | 原生中性轻卡片、轻圆角 |
| 轮廓 | 1px 青蓝弱线 + 12px 统一切角 | 中性灰系边框 |
| 控件 | 线框 + 清楚的焦点与选中高亮 | 与 DSH 一致的常规按钮/复选框 |
| 功能强调 | 适量柔和青蓝 | 极少量青蓝品牌细节 |
| 文本 | 高对比雾白 + 蓝灰副文本 | 继承 DSH 文字 CSS 变量或容器默认 |

## 功能必须保持不变

- 公开 GitHub 的 `plugins/index.json`、`released/index.json`、`unstable/index.json` 来源与 SHA-256 校验逻辑不改。
- 「检查更新」只请求 Host 重新获取索引，不自动安装；三项自动更新授权默认/限制不变。
- HUD 视觉改版不改 `hudMode` 开关语义，不更改 Session、审批流程、平台 Runner 配置或其他插件。
- 未经用户另行明确批准，不晋升 Released；用户当前已安装 V0.5.1 不会由 CI 自动覆盖。
