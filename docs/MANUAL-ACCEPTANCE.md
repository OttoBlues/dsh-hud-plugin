## HUD V0.4.0 · U04 匿名更新与侧栏验收（2026-11-05，用户截图与明确反馈）

用户从 HUD V0.3 手动触发 V0.4 `unstable` 更新后，报告 U04 的四项任务均完成：公开源匿名检查、V0.3 检测到 V0.4 并提供更新、重启后版本为 V0.4、独立左侧 HUD 入口和组件中心正常显示。

**必须另记一条失败项**：更新执行过程中 DSH Desktop 曾显示「应用无法启动或已意外停止」，堆栈涉及 HUD 的异步 `processManualRequest` / `writeSettings` 和 DSH 的 `Proxy.edit/Object.apply`。重启后 V0.4 可正常使用。**U04 用户功能四项均通过，热更新稳定性及不中断 DSH 未通过**，不能报告整个升级过程无故障。

- 后续缺陷追踪：`U04-R1` — 自更新时旧 Host 继续写入配置或异步任务异常导致宿主启动失败的风险。
- 经核对上游 DSH `configEditor.edit` 在 Entry 不再存在、Fiber 失活或重载中会拒绝编辑，因此这是可能的竞态原因，但未取得完整 crash 日志，**不能认定为唯一确定根因**。
- 用户截图中的「接收试验版更新」「自动更新正式版」「自动更新试验版」均为已勾选状态；`Schema.default(false)` 仅作用于无保存值时，不覆盖既有偏好。修复与后续试验版发布前应关闭自动更新两个开关。
- V0.4 是 `unstable/` 试验版；`released/` 保持空，不得因 U04 功能验收升级为正式发布。
