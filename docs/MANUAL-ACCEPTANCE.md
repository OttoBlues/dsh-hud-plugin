# DSH HUD 人工验收清单

每当完成相关功能后，在真正的 Windows 桌面中测试。当前 V0.1 是窗口内静态预览，大多数原生 HUD 功能尚未开发。

| ID | 用户验证项目 | 通过标准 | 现状 |
| --- | --- | --- | --- |
| U01 | 打开 DSH，安装预览插件并确认 HUD 显示 | 四角及底部提示可见且不会遮挡原界面 | 待人工验证 |
| U02 | 卸载 HUD 插件并重启 DSH | 正常回到原界面，Session 不丢失 | 待人工验证 |
| U03 | Windows 桌面透明置顶 | 背后桌面/IDE/游戏可见，HUD 无大块底色 | 功能待开发 |
| U04 | 静默模式点击穿透 | 点击桌面和游戏不被 HUD 截获 | 功能待开发 |
| U05 | 长按专用键 1 秒唤醒和静默 | 不误触发系统快捷键，切换可靠 | 功能待开发 |
| U06 | 激活态底部输入与弹出面板 | 可正常输入、焦点恢复，交互区可点击 | 功能待开发 |
| U07 | 多显示器和 DPI 100%/125%/150% | 四角与交互区域位置准确 | 功能待开发 |
| U08 | 游戏全屏/无边框窗口覆盖 | 明确记录支持情况，无异常抢焦点 | 功能待开发 |
| U09 | 切换 HUD / 关闭主窗时正在执行任务 | Agent、Run、Session 不被意外中断 | 功能待开发 |
| U10 | DSH 审批弹窗 | 高风险批准/拒绝始终可见且可操作 | 功能待开发 |

**禁止把 Node.js 单元测试或 HTTP 响应等同于 GUI 验收。** 每项需要用户实际观察及反馈。
