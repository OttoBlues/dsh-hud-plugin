## 当前行动

- 验证新仓库地址 `OttoBlues/dsh-hud-plugin` 的无痕访问和 GitHub 连接授权。
- 已通过云端 CI 验证 V0.4.2 固定安装包并加入 Unstable；用户确认本机升级成功、无报错、无需手动重启。
- 继续核对 HUD 的中英文仓库说明、新 Raw 源和故障处理；后续可评估更新后保留 HUD 页面而非返回主会话。
- 不再启用本机 Actions Runner，CI 不再具备部署或卸载 Desktop 的路径。
- 区分当前插件组件热重载与整个 DSH 进程重启（尚未验证）；Released 通道仍为空，未经用户明确批准不得升为正式版。

## V0.5.0 工作区阶段

- 先实现安全可逆的 HUD 视觉工作区，保留原 DSH 主会话和所有权限。
- 在 HUD 中提供总览、真实会话状态和返回 DSH/组件中心的可见出口。
- 对新版本的 U05 验收重点：默认 DSH、进出 HUD 不丢失 Session、更新或插件停用不锁住原 UI。
- Windows 系统级透明置顶/点击穿透仍属于之后的 M4，而不是本次全帧 HUD 工作区。

## V0.5.1 用户视觉验收目标

- HUD 工作区从大块圆角 Dashboard 改成矢量切角、可辨读的细线框驾驶舱面板。
- 组件中心同步采用同套切角面板、控件描边及轻微网格。
- 用户点击「检查更新」应在当前 DSH 会话里更新索引，不必重启应用；不自动安装。
- 错误场景必须解释失败的是仓库总索引还是某个发布通道，不得显示假的“已是最新”。
- 仍需用户实机确认颜色强度、信息密度、视觉节奏和 HUD/DSH 切换可靠后才敲定视觉规范。
