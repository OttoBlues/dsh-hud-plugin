# DSH HUD · V0.4.1 Unstable 试验版

这是仓库根的一个 DSH Cordis 插件，其自身拥有「HUD」左侧导航入口和独立的 HUD 组件管理主界面。

- 使用 `sidebar.panellist` 和独立 `main` 注册，完全移除旧 `plugins.tab`；不再修改 DSH 原生插件页面的「已安装/组件」分栏。
- 主界面从 `../index.json` 发现本仓库的全部组件，包括未安装的组件。
- 只从 `released/` 和显式允许的 `unstable/` 下载、校验和安装固定 `.tgz`。
- 允许手动更新、默认关闭的正式版自动更新，及需要额外授权的试验版自动更新。
- HUD 聊天窗口覆盖默认关闭。

V0.4.0 已通过用户 U04 的匿名更新和 UI 验收，但在自更新过程中曾导致 DSH 异常退出；`released/` 仍为空。

## V0.4.1 自更新修复试验版

针对用户 U04 中升级 V0.4 时宿主崩溃的实机反馈，增加生命周期保护、错误拦截和重新启动后的版本核验；在 GitHub 仓库更名前同时兼容旧名 `dsh-plugins` 与规划新名 `dsh-hud-plugin`。仅在 `unstable/` 列出经校验的试验包；发布前请关闭 V0.4.0 的自动更新正式版和自动更新试验版开关。本版尚未经实机无中断自更新验收。
