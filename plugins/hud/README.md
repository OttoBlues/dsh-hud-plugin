# HUD · 最新开发源码（V0.3，未发布）

本目录中的 Host、Client、测试、配置可以包含尚不稳定的研发功能。**禁止从本目录直接提取源码作为用户可安装包。**

- `released/`：用户明确批准且完成验收后，才纳入安装包。
- `unstable/`：CI 检查通过并决定进行真实测试后纳入试验包。
- 两个通道当前均无安装包；V0.1 与 V0.2 既有验收记录不会擅自转化为正式发布。
- 组件页新增试验版更新开关（默认关闭），只有已安装相应新开发版插件才能显示；在用户点击具体更新后，Runner 才会在安全退出 DSH 后安装。
- 为修复截图中的文字重叠，开发版 HUD 的窗口内覆盖预览默认隐藏，可在组件页另行启用。该预览仍不是 Windows 原生全屏透明 HUD。

参考 `docs/RELEASE-POLICY.md`、`docs/AUTO-UPGRADE.md`。
