# DSH HUD · V0.4 开发版（尚未发布）

这是仓库根的一个 DSH Cordis 插件，其自身拥有「HUD」左侧导航入口和独立的 HUD 组件管理主界面。

- 使用 `sidebar.panellist` 和独立 `main` 注册，完全移除旧 `plugins.tab`；不再修改 DSH 原生插件页面的「已安装/组件」分栏。
- 主界面从 `../index.json` 发现本仓库的全部组件，包括未安装的组件。
- 只从 `released/` 和显式允许的 `unstable/` 下载、校验和安装固定 `.tgz`。
- 允许手动更新、默认关闭的正式版自动更新，及需要额外授权的试验版自动更新。
- HUD 聊天窗口覆盖默认关闭。

**尚未正式发布或安装 V0.4.0**。已安装的 V0.3.0 继续可用，`released/` 不晋升任何版本。
