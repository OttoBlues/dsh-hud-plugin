# HUD v0.3.0 · 试验构建源码

V0.3 已于 2026-11-04 安装进 DSH Desktop，旨在实现「插件 → 组件」页面的版本更新 UI，不再把状态文字默认叠加在标题栏和聊天输入区。

- `plugins/hud/unstable`：已登记并真实安装 v0.3.0 试验包；不是正式发布。
- `plugins/hud/released`：保持空；待用户明确确认一个稳定里程碑后才发布。
- 组件页试验版开关默认关闭，只有打开开关且版本更新才显示试验版按钮；点击后再次确认。
- Host 自行通过匿名 HTTPS 检查公开版本清单，校验 SHA-256 并调用官方 DSH 插件管理服务。**本仓库仍 Private 时，不可能匿名读取更新**，后续公开后可停止 Runner。
- 由于既有 V0.2 与窗口框架重叠，新的预览浮层默认隐藏，需自行在组件页开启。

引导安装后需人工测试 V0.3 UI；不能仅凭 Windows CLI 安装成功就称功能全部完成。
