# HUD · Unstable Test Packages

**测试安装包专用目录，默认不会被安装或通知为常规更新。**

当前已有经 GitHub Actions 检查的 **HUD v0.3.0 试验包**，它只用于你明确要求的单次 Runner 引导安装，**绝不是 released 正式版**。

不稳定版本由可信 CI 构建，并在确认需要真实测试时单独加入此目录。允许尚未通过完整人工验收，但必须记录来源提交、安装包 SHA-256、测试状态和风险提示。不得下载根目录最新版源码代替测试安装包。

`index.json` 只指向已实际登记的试验安装包；当前包含 v0.3.0、v0.4.0 和 v0.4.1（U04-R1 修复候选）。

客户端组件页提供「允许试验版更新」开关，默认关闭；开启后才显示 `unstable/` 的可用版本。为避免误操作，**试验版仍必须明确点击更新并确认**，不会仅因开启开关或推送源码就自动安装。

目录范式：

```
unstable/
  index.json
  vX.Y.Z/
    local-dsh-hud-X.Y.Z.tgz
    manifest.json
```

测试版有回退风险，自动化不得强制关闭 DSH；必须在安全退出后才替换包。
